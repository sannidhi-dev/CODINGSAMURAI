IMPORTANT
1. Put your professional photo in this folder and name it exactly: profile.jpg
2. Put your resume in this folder and name it exactly: resume.pdf
3. In index.html replace:
   https://www.linkedin.com/in/YOUR-LINKEDIN-USERNAME
   with your real LinkedIn URL.
4. Replace:
   https://github.com/YOUR-GITHUB-USERNAME
   with your real GitHub URL.
5. Open index.html with VS Code Live Server.
